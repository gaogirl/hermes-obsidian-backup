# Hermes Agent

Hermes Agent 是当前使用的代理框架，提供技能、持久记忆、文件与终端工具、定时任务、MCP、消息网关以及多平台代理执行能力。

## 对本知识库的关系

- 定时任务会将 AI 资讯、精选与维护结果写入本 Obsidian 知识库。
- [[MCP Python SDK]] 可用于按标准协议扩展工具能力。
- [[Hugging Face Skills]] 可作为可审查的外部工作流与 skill 候选来源。
- [[MarkItDown]] 可在经过验证后辅助更多文件格式的知识摄取。

## 来源与边界

- GitHub：https://github.com/NousResearch/hermes-agent
- 许可证：MIT
- 当前状态：本机正在使用；不在知识库重复克隆。
- 边界：配置变更必须使用 Hermes CLI；外部 skill、插件、MCP 和脚本必须先审查权限与副作用。
