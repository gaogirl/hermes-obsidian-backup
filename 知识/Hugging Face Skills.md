# Hugging Face Skills

`huggingface/skills` 是 Hugging Face 维护的 Agent Skills 集合。README 列出覆盖 Hub CLI、模型/数据集检索、论文、评估、训练、部署、Spaces 和本地模型等工作流的技能定义。

## 对代理的价值

- 为 [[AI代理能力资源库]] 提供经过结构化描述的 AI/ML 工作流候选。
- 可作为寻找模型、数据集、论文与评估方法的资料入口。
- 其 Agent Skills 格式也可为编写和维护 [[Hermes Agent]] skills 提供参考。
